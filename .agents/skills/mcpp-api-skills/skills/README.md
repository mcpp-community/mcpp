# Skills

**English** | [简体中文](README.zh-CN.md)

mcpp guidance grouped by task. Each skill covers one topic with the commands, configuration syntax and examples needed to use it.

| Category | Topics |
| --- | --- |
| [Getting started](basics/README.md) | Installation, project creation and the commands used for a first build. Start here for a new project or a package template. |
| [Project configuration](project-config/README.md) | The tables that make up mcpp.toml: package identity, product targets, modules, build options, features and workspaces. |
| [Building and testing](workflow/README.md) | Build and run programs, select tests, and manage the dependencies and indices used by a project. |
| [Toolchains and runtimes](toolchains/README.md) | Compiler selection, cross-compilation, runtime linkage and external tools. These skills cover which compiler, target and environment a build uses. |
| [Build extensions](extensions/README.md) | Write build.mcpp programs and reusable rules with the public C++ API. Extension packages can provide tools, platforms, runtimes and packaging formats. |
| [Packaging and publishing](packaging/README.md) | Create application bundles and library packages, then prepare the descriptors and index entries needed to distribute them. |
| [Devices and heterogeneous builds](devices/README.md) | Build and run code for devices, accelerators and freestanding targets. Compiler setup, runner selection and execution are separate parts of these workflows. |
| [Program interfaces](integration/README.md) | Drive mcpp from agents, editors or CI. Parse machine output, inspect launch descriptions and export the build database. |
| [Environment and troubleshooting](operations/README.md) | Inspect homes and caches, explain build decisions and diagnose failures before changing the environment. |

[Look up a command, manifest key or API](INTERFACES.md).
