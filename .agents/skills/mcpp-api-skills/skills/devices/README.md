# Devices and heterogeneous builds

**English** | [简体中文](README.zh-CN.md)

Build and run code for devices, accelerators and freestanding targets. Compiler setup, runner selection and execution are separate parts of these workflows.

| Skill | Topic |
| --- | --- |
| [mcpp-devices](mcpp-devices/SKILL.md) | Default/named runners, device access and exclusive execution |
| [mcpp-heterogeneous-builds](mcpp-heterogeneous-builds/SKILL.md) | Accelerator selection, device languages and host/device interfaces |
| [mcpp-freestanding](mcpp-freestanding/SKILL.md) | Bare-metal targets, BSPs, startup code and linker scripts |
