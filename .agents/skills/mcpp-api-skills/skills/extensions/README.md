# Build extensions

**English** | [简体中文](README.zh-CN.md)

Write build.mcpp programs and reusable rules with the public C++ API. Extension packages can provide tools, platforms, runtimes and packaging formats.

| [mcpp-build-actions](mcpp-build-actions/SKILL.md) | Generated sources, checks, objects, artifacts and prepare actions |
| [mcpp-rule-packages](mcpp-rule-packages/SKILL.md) | Rule modules, host tools and build-time reexports |
| [mcpp-toolchain-providers](mcpp-toolchain-providers/SKILL.md) | Toolchain discovery, bootstrap and tool roles |
| [mcpp-platform-packages](mcpp-platform-packages/SKILL.md) | Platform layers, link settings, runners and carriers |
| [mcpp-payloads-and-adapters](mcpp-payloads-and-adapters/SKILL.md) | Prebuilt payloads, runtime adapters, BSPs and custom formats |
