# 构建扩展

[English](README.md) | **简体中文**

使用公开 C++ API 编写 build.mcpp 和可复用规则，通过扩展包提供工具、平台、运行时或打包格式。

| Skill | 内容 |
| --- | --- |
| [mcpp-build-programs](mcpp-build-programs/SKILL.md) | build.mcpp 生命周期、输入、执行阶段和诊断 |
| [mcpp-build-api](mcpp-build-api/SKILL.md) | mcpp.core 函数、action 方法和指令作用域 |
| [mcpp-build-actions](mcpp-build-actions/SKILL.md) | 生成源文件、检查、目标文件、产物和 prepare action |
| [mcpp-rule-packages](mcpp-rule-packages/SKILL.md) | 规则模块、宿主工具和构建时依赖转发 |
| [mcpp-toolchain-providers](mcpp-toolchain-providers/SKILL.md) | 工具链探测、bootstrap 和工具角色 |
| [mcpp-platform-packages](mcpp-platform-packages/SKILL.md) | 平台层、链接设置、runner 和 carrier |
| [mcpp-payloads-and-adapters](mcpp-payloads-and-adapters/SKILL.md) | 预构建组件、运行时适配、BSP 和自定义格式 |
