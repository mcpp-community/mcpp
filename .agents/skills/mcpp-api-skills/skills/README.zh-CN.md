# 技能分类

[English](README.md) | **简体中文**

按任务分类的 mcpp 使用指南。每个 skill 聚焦一个主题，包含对应的命令、配置语法和示例。

| 分类 | 内容 |
| --- | --- |
| [入门](basics/README.zh-CN.md) | 安装 mcpp、创建工程并完成首次构建。新建项目、使用包模板或查找常用命令时，从这里开始。 |
| [工程配置](project-config/README.zh-CN.md) | mcpp.toml 的主要配置：包信息、产品目标、模块、编译选项、特性和工作空间。 |
| [构建与测试](workflow/README.zh-CN.md) | 构建和运行程序、选择测试，以及管理工程使用的依赖和包索引。 |
| [工具链与运行时](toolchains/README.zh-CN.md) | 编译器选择、交叉编译、运行时链接和外部工具，用于配置构建所需的编译器、目标平台和工具环境。 |
| [构建扩展](extensions/README.zh-CN.md) | 使用公开 C++ API 编写 build.mcpp 和可复用规则，通过扩展包提供工具、平台、运行时或打包格式。 |
| [打包与发布](packaging/README.zh-CN.md) | 制作应用包和库包，并准备分发所需的描述文件与索引条目。 |
| [设备与异构构建](devices/README.zh-CN.md) | 为设备、加速器和 freestanding 目标构建与运行程序，涵盖设备编译器、runner 和运行环境。 |
| [程序接口](integration/README.zh-CN.md) | 从 agent、编辑器或 CI 调用 mcpp，解析机器输出、获取启动描述和导出构建数据库。 |
| [环境与排错](operations/README.zh-CN.md) | 检查 home 和缓存、查看构建决策，并依据诊断信息定位故障。 |
