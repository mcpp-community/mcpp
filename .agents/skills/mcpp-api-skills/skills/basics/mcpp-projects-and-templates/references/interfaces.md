# Projects And Templates Reference

Interface names and declarations for mcpp 2026.10.31.3.

## Commands and options

| Interface | Form | Description |
| --- | --- | --- |
| `mcpp new` | command | Create a new mcpp package skeleton |
| `mcpp new --list-templates` | value | List templates from exact [ns.]pkg[@ver] |
| `mcpp new --template` (`-t`) | value | bin (default) \| [ns.]pkg[@ver][:template] — exact package template |
| `mcpp new <name>` | optional argument | Package directory name |
